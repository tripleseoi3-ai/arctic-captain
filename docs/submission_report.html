1 작품 개요

북극항로 선장 시뮬레이터(Arctic Captain)는 북극항로와 극지 해빙 변화를 처음 배우는 해양대 재학생 및 해운·기후 교양 수강생이 실제 관측·예측 데이터를 직접 조작하며 학습할 수 있도록 만든 모바일 우선(PC 반응형) 교육용 웹 시뮬레이터입니다. 미국 국립빙설자료센터(NSIDC)의 공식 월별 북극 해빙 면적(1979~2026)과 시계열 예측 모델(기준선 vs SARIMA)을 바탕으로 ① 항해 가능 달력 탐색 → ② 5단계 선장 출항 미션 퀴즈 → ③ 1979~2035 장기 추세·기후 인사이트의 학습 루프를 구현했습니다.

2 해결하려는 문제 및 차별성

❗ 해결하려는 문제 (누가 · 언제 · 무엇이 불편한가)

북극항로를 처음 배우는 해양대 재학생이 해빙 면적 변화에 따른 출항 가능 시기를 공부할 때, 교과서나 정적인 그래프만으로는 직관적 체감이 어렵고 전문가용 극지 항해 분석 도구는 학생이 직접 조작하며 학습하기에 지나치게 복잡합니다.

✨ 기존 같은 주제 작품과의 차별점

기존 북극 해빙·기후변화 작품이 예측 그래프를 보기만 하는 대시보드에 그치는 것과 달리, 선박 등급 프리셋·임계값 슬라이더로 항해 가능 달력을 직접 바꾸고 실제 실측·SARIMA 예측 수치 기반의 5단계 선장 미션 퀴즈로 의사결정까지 훈련하는 점이 다릅니다.
