1 작품 개요 · 문제 정의 및 차별성

🎯 대상 (Who)

북극항로(NSR)와 극지 해빙 변화를 처음 배우는 해양대 재학생(항해·해운 전공 입문자) 및 기후·해양 교양 수강생

❗ 해결하려는 문제 (Problem)

교과서·정적 그래프만으로는 해빙 감소에 따른 출항 시기 변화를 체감하기 어렵고, 전문가용 극지 운항 도구는 학생이 직접 조작하며 학습하기에 지나치게 복잡함

✨ 차별성 (Uniqueness)

단순 예측 차트에 그치지 않고 ① 선박 등급별 시뮬레이션 달력 → ② 선장 의사결정 퀴즈 → ③ 장기 추세·기후위기 인사이트로 이어지는 학생 맞춤형 학습 루프 구현

3 실측 데이터 전처리 및 예측 모델 비교 (NSIDC Sea Ice Index v4.0)

미국 국립빙설자료센터(NSIDC) 공식 월별 북극 해빙 면적(G02135 v4.0, 1979년 1월~2026년 10월, 총 574개월)을 수집했습니다. 위성 센서 교체로 발생한 2개월 결측(1987-12, 1988-01)은 인접 연도 동월 평균으로 보간했으며, 1979~2020년 학습 후 최근 5년(2021~2025, 60개월) 홀드아웃 검증으로 두 모델을 비교했습니다.

예측 모델 모델 수식 · 특징 검증 MAE 검증 RMSE 2030년 9월 예측

4 생성형 AI(바이브코딩) 활용 과정 및 문제 해결·개선 사례

STEP 1 · 기획(PRD)
범위 축소 및 3탭 설계

복잡한 GIS 지도를 제외하고 북극 전체 월별 면적에 집중. AI와 기능 3개·화면 3개·저장 방식 기획표(PRD)를 선확정

STEP 2 · 데이터·모델
실측 수집 및 SARIMA

NSIDC v4.0 CSV 12종 자동 수집·결측 보간·기준선 vs SARIMA 추정 및 95% 신뢰구간 사전 계산 파이프라인 구축

STEP 3 · 단계별 구현
화면 1→2→3 점진 빌드

첫 화면(달력)을 모바일에서 먼저 검증한 뒤 선장 퀴즈(화면 2), SVG 장기 추세 그래프(화면 3)를 순차 추가

STEP 4 · 배포·검증
무중단 정적 호스팅

DOM ID 자동 정합성 검사, 57년×12개월 데이터 검증 후 GitHub Pages 정적 배포로 HTTPS 상시 접속 확보

발생한 문제 / 초기 한계 AI 협업 프롬프트 및 해결·개선 과정 개선 결과
① 무료 서버 슬립 및 로컬 실행 환경 제약 실시간 Python 서버 배포 시 심사 중 슬립·접속 불가 위험을 발견. AI와 협의해 사전 계산 스크립트로 JSON/JS 데이터를 미리 추출하고, 외부 차트 라이브러리 없는 순수 정적 웹(HTML/CSS/JS+SVG)으로 전환 GitHub Pages 기반 1초 이내 로딩·심사 기간 100% 무중단 접속 및 모바일 최적화 달성
② 단순 면적 슬라이더의 낮은 직관성 "해빙 면적 5.5 M km²" 숫자만 제시하면 학습자가 체감하기 어렵다는 피드백을 반영해, 해양 전공 개념을 녹인 선박 등급 프리셋 3종(일반 상선·내빙선·쇄빙선)을 우선 배치하고 미세 조정 슬라이더를 하단에 결합 클릭 1회로 선박 성능별 출항 가능 월 차이를 비교할 수 있어 사용자 편의성·교육성 동시 향상
③ 예측 모델 비교의 학습 연결 부족 단순 4지선다 퀴즈 대신 실제 데이터에서 모델 판정이 엇갈리는 2030년 11월(기준선 8.91 가능 vs SARIMA 9.04 주의)과 2035년 10월 신뢰구간 상한 초과 사례를 AI로 탐색해 미션 4·5번에 반영 통계 모델 검증(MAE/RMSE)과 미래 예측 불확실성까지 배우는 데이터 리터러시 퀴즈 완성

5 교육적 활용 방안 및 이용 방법

🎓 대학 전공·교양 수업 활용 시나리오 (3단계)

  • 1단계 탐색 (10분): 학생이 휴대폰으로 접속해 1985→2024→2030년과 선박 등급을 바꿔보며 통항 가능 월 변화를 직접 기록
  • 2단계 실습 평가 (10분): 선장 퀴즈 5단계 미션 수행 후 최종 선장 등급 리포트 확인 및 틀린 문제만 다시 풀기로 오개념 보완
  • 3단계 토론 마무리 (10분): 추세·안내 화면의 1979~2035 그래프와 항로 단축 vs 기후위기 카드를 보며 해운 경제성과 극지 환경 보전 딜레마 토론

📱 서비스 이용 방법 (설치·회원가입 불필요)

  • 접속: 모바일·PC 브라우저에서 https://tripleseoi3-ai.github.io/arctic-captain/ 접속
  • 달력 시뮬레이션: 상단 연도·빠른 이동 버튼과 하단 선박 프리셋·슬라이더를 조작하고 1~12월 셀을 터치해 상세 판정 확인
  • 퀴즈 도전: 하단 선장 퀴즈 탭에서 힌트 데이터·달력 연동 기능을 활용해 5문항 풀이 후 리포트 확인
  • 추세 확인: 하단 추세·안내 탭에서 그래프 전환(가능 개월 수 ↔ 9월 면적) 및 모델 검증표 열람

6 교육용 한계 고지 및 향후 발전 방향

⚠️ 교육용 시뮬레이터 한계 명시 (신뢰성 및 안전성 원칙)
본 서비스는 미국 NSIDC의 북극 전체 월별 해빙 면적(Extent)만을 단순화하여 만든 교육·학습 전용 시뮬레이터입니다. 실제 북극항로 운항 의사결정에는 구간별 해빙 두께·밀집도, 기상·해류, 쇄빙 지원 여부 및 IMO 극지코드(Polar Code) 규정이 필수적이므로 실제 운항 판단용으로 사용할 수 없습니다. (웹앱 첫 화면·모달·안내 탭에 상시 고지)

🔧 기술적 완성도 및 확장성

브라우저 localStorage로 마지막 선박 설정·최고 점수·오답 목록을 자동 저장하며, 사전 계산 데이터 스크립트 재실행만으로 신규 월별 NSIDC 실측 데이터를 손쉽게 업데이트할 수 있는 구조입니다.
